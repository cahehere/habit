100일 습관 트래커

매일 하는 습관을 간단히 체크하고, 연속 기록과 5주 달력으로 꾸준함을 확인하는 웹앱 기획서

1. 한 줄 소개

누가: 매일의 습관을 만들고 싶은 사람이 언제: 하루 한 번, 왜: 100일 목표를 꾸준히 실천하고 변화를 눈으로 확인하기 위해 쓰는 앱입니다.

핵심 원칙: 기록은 사용하는 사람의 브라우저에만 저장합니다. 앱 주소를 공유해도 다른 사람에게 내 기록은 보이지 않습니다.

4. 배포 방법

  1. GitHub에 로그인하고 새 저장소를 만듭니다. 저장소 이름은 예를 들어 habit-tracker로 정합니다.
  2. 이 프로젝트의 index.html 파일을 저장소에 올립니다. 파일 이름은 반드시 index.html이어야 합니다.
  3. GitHub 저장소에서 Settings → Pages로 들어갑니다.
  4. 배포 방법에서 Deploy from a branch를 선택하고, main 브랜치와 /(root)를 선택한 뒤 저장합니다.
  5. 잠시 기다리면 https://사용자이름.github.io/저장소이름/ 형태의 주소가 생깁니다.
  6. 그 주소를 복사해 공유합니다. 주소를 받은 사람은 앱 화면은 보지만 내 기록은 보지 못합니다.
주의: GitHub에 올린 HTML 파일은 누구나 볼 수 있습니다. 이름, 이메일, 비밀번호, 개인 기록을 코드에 직접 넣지 않습니다.

5. 테스트 체크리스트 10개

  1. 계산: 오늘 아직 체크하지 않으면 어제까지의 연속 일수가 표시된다.
  2. 계산: 어제를 걸렀다가 오늘 체크하면 연속 일수가 1일이 된다.
  3. 계산: 이틀 이상 걸렀다가 오늘 체크하면 기존 기록이 끝나고 1일부터 다시 시작한다.
  4. 계산: 오늘 체크 후 해제하면 체크 전의 연속 일수로 돌아간다.
  5. 계산: 연속 기록이 끊겨도 최장 기록과 달성률은 올바르게 보존된다.
  6. 입력 오류: 습관 이름을 빈칸으로 등록할 수 없다.
  7. 입력 오류: 습관을 6개 등록한 뒤 7번째 등록이 막힌다.
  8. 입력 오류: 삭제 버튼을 누르면 확인하지 않고는 삭제되지 않는다.
  9. 배포·공유: GitHub Pages의 HTTPS 주소에서 PC와 휴대폰 화면이 모두 열린다.
  10. 배포·공유: 다른 브라우저에서 주소를 열었을 때 내 기록이 보이지 않고 별도 기록으로 시작한다.

제작 요청 요약

  1. index.html 하나로 100일 습관 트래커를 만든다.
  2. 사용자는 습관을 최대 6개까지 등록한다.
  3. 습관 이름은 빈칸과 30자 초과를 허용하지 않는다.
  4. 습관은 확인 후 삭제할 수 있다.
  5. 오늘 날짜만 체크하고 다시 누르면 해제한다.
  6. 오늘 미체크 시 어제까지의 연속 일수를 유지한다.
  7. 빠진 날 뒤 체크하면 1일부터 다시 센다.
  8. 최장 기록은 연속 기록이 끊겨도 보존한다.
  9. 최근 35일을 5주 달력으로 보여준다.
  10. 달성률은 완료 날짜 수를 100일 기준으로 계산한다.
  11. 기록은 브라우저 저장공간에만 저장한다.
  12. 개인정보와 기록을 HTML 코드에 넣지 않는다.
  13. PC와 휴대폰에서 보기 좋게 반응형으로 만든다.
  14. 페이지 제목과 설명을 설정한다.
  15. GitHub Pages에서 HTTPS로 공유할 수 있게 한다.
